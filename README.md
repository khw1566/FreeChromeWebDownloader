# Media Downloader Pro

일반 MP4/WebM/오디오 파일과 유튜브 등 영상 페이지를 같은 목록에서 선택해 다운로드합니다. 영상과 음성이 분리된 DASH/HLS 스트림은 PC 보조 프로그램에서 다운로드하고 FFmpeg로 합칩니다. MP3 음원 저장도 지원합니다.

## Windows 최초 설치

1. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**로 이 폴더를 선택합니다. 이미 로드했다면 새로고침 버튼을 누릅니다.
2. 확장 프로그램 카드의 **ID**를 복사합니다.
3. Python 3.10 이상과 [FFmpeg](https://ffmpeg.org/download.html) (`ffmpeg`, `ffprobe`), [Deno](https://deno.com/) 또는 지원되는 [Node.js](https://nodejs.org/)를 설치하고 PATH에 추가합니다. YouTube JavaScript 처리에는 최신 런타임이 필요합니다.
4. PowerShell에서 이 폴더로 이동한 후 아래 명령으로 Python 패키지를 설치합니다.

   ```powershell
   python -m pip install -U "yt-dlp[default]"
   ```

5. 아래 명령의 ID를 2번에서 복사한 실제 값으로 바꿔 실행합니다.

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\native\install.ps1 -ExtensionId 실제확장프로그램ID
   ```

   Python이 여러 개라면 `-PythonPath "C:\경로\python.exe"`를 추가하세요. 설치 스크립트는 현재 사용자 Chrome 네이티브 호스트 레지스트리 키와 이 폴더 안의 실행 파일/설정 파일을 작성합니다. 관리자 권한은 필요하지 않습니다. 이 폴더를 옮기면 다시 등록하세요.

6. Chrome을 완전히 종료한 후 다시 실행하고 확장 프로그램의 **연결 확인**을 누릅니다.

## 사용

보조 프로그램을 프로젝트 전용 환경(`native/.venv`)에 설치한 경우 업데이트 명령은 아래와 같습니다.

```powershell
.\native\.venv\Scripts\python.exe -m pip install -U "yt-dlp[default]"
```

`native/tools/ffmpeg`에 FFmpeg를 배치하면 보조 프로그램이 자동으로 찾습니다. 시스템 PATH를 바꿀 필요가 없습니다.

1. 영상 페이지를 열면 기존 미디어 목록에 **현재 페이지 영상**과 감지된 파일이 함께 나옵니다. 유튜브의 개별 CDN 스트림은 현재 페이지 영상 항목으로 통합합니다.
2. 여러 항목의 체크박스를 선택하거나 **전체 선택**을 누릅니다. 전체 선택은 현재 필터에 표시되는 항목에 적용됩니다.
3. 저장 형식에서 **영상 / 원본** 또는 **MP3 음원**을 고르고 **선택 다운로드**를 누르세요. 한 번에 최대 100개, 최대 3개씩 동시에 처리하고 나머지는 대기합니다. 이미 진행 중인 같은 주소·형식은 중복 추가하지 않습니다.
4. 개별 항목의 **MP3** 버튼으로 바로 192kbps MP3를 저장할 수도 있습니다. 유튜브를 포함한 페이지 영상과 감지된 일반 파일 모두 지원하며, MP3에는 보조 프로그램이 필요합니다.
5. **여러 영상 주소 추가**를 펼치고 유튜브 등 페이지 주소를 한 줄에 하나씩 붙여넣으면 여러 영상을 한 번에 목록에 추가할 수 있습니다. 재생목록 주소는 현재 영상만 처리합니다.

진행 상태는 같은 화면의 **다운로드 진행**에 파일별 프로그래스 바로 표시됩니다. 전체 바는 완료 또는 실패로 처리된 파일 수를 표시합니다. 파일 크기를 알 수 없거나 FFmpeg로 변환·병합할 때는 움직이는 처리 중 막대를 표시합니다. 영상과 음성을 따로 내려받는 경우 각 스트림의 진행률을 표시하므로 다음 스트림에서 진행률이 다시 시작될 수 있습니다.

팝업을 닫아도 다운로드가 계속되고, 다시 열면 작업 상태를 복원합니다. 확장 프로그램을 다시 로드하면 연결이 끊길 수 있으므로 진행 중인 다운로드가 끝난 후 로드하세요.

페이지 영상/MP3는 사용자 `Downloads\Media Downloader` 폴더에 저장됩니다. 일반 원본 파일은 Chrome의 기본 다운로드 폴더 아래 `Media Downloader`에 저장하며, 브라우저에서 항상 저장 위치를 묻도록 설정했다면 확인 창이 나올 수 있습니다. 페이지 영상은 호환성에 따라 MP4 또는 MKV로 저장됩니다. 최고 화질/최대 1080p/최대 720p는 페이지 영상과 분할 스트림에 적용됩니다. 일반 원본 파일은 원본 화질로 저장합니다.

확장 프로그램 새로고침 후 기존 웹 페이지도 새로고침해 주세요. 이미 설치한 보조 프로그램은 다시 등록하지 않아도 됩니다.

사이트마다 지원 여부가 다르며 DRM 보호 영상은 지원하지 않습니다. 로그인/유료/지역 제한 영상은 실패할 수 있습니다. 브라우저 쿠키를 자동으로 읽거나 전송하지 않습니다. 다운로드 가능한 권한이 있는 영상에 사용하세요. 사이트 변경으로 실패하면 `python -m pip install -U "yt-dlp[default]"`로 갱신하세요.

## 속도 개선 (1.2.1)

기본 화질은 최대 1080p입니다. **최고 화질 · 대용량**을 선택하면 4K 등 큰 파일을 받을 수 있으므로 전체 시간이 늘어날 수 있습니다. 유튜브는 같은 해상도·프레임 수·HDR 조건을 만족하는 HLS 영상이 있으면 우선 사용하며, 원래 선택된 음성 언어는 유지합니다. 분할 스트림은 최대 4개 연결로 다운로드합니다. 유튜브의 숨겨진 스트림과 개별 조각에는 별도 크기 확인 요청을 보내지 않습니다.

진행 바 아래에 실제 전송 속도, 내려받은 용량, 현재 스트림의 예상 남은 시간을 표시합니다. 표시된 남은 시간에는 다음 음성 스트림 다운로드와 변환 시간이 포함되지 않을 수 있습니다. 네트워크와 유튜브 서버 응답에 따라 속도가 달라집니다. 변경 사항은 확장 프로그램을 새로고침한 후 새로 시작한 작업에 적용됩니다.

## 제거

Chrome에서 확장 프로그램을 제거한 다음 PowerShell에서 보조 프로그램 등록을 삭제할 수 있습니다.

```powershell
Remove-Item -LiteralPath 'HKCU:\Software\Google\Chrome\NativeMessagingHosts\com.media_downloader.helper'
```
